# 番茄小说工作室（fanqie-novel-studio）

网文长篇创作全流程 skill：**世界观一问一答设定法、章节评分卡工艺、章末钩子硬标准、节奏硬规则、评论诱导、写前中后流程、番茄改稿对比学习、批次管理**。

> 由真实长篇创作过程提炼（世界观 106 问+续问逐条核对、评分卡星级体系、番茄草稿箱改稿对比学习），作者拍板沉淀。可自由 fork、修改、再发布。

## 两个版本

| 版本 | 位置 | 依赖 | 适用 |
|---|---|---|---|
| **公开版** | 仓库根 `SKILL.md` | 无（纯 Markdown 文件工作流） | Claude Code / Cursor / SkillHub / 任意 LLM 环境 |
| **DSH 版** | `DSH版/SKILL.md` | DSH + dsh-novel-writer 插件（novel_* 工具） | DeepSeek Harness 用户，工具层自动化 |

两版工艺内容一致，区别只在「工具层」：公开版用纯文件工作流（§6 数据层文件约定），DSH 版内置 novel_* 工具映射表（词表/数值/语义/审计自动化）。

## 安装

### 公开版（Claude Code）

```bash
mkdir -p ~/.claude/skills
# 把本仓库克隆到 ~/.claude/skills/fanqie-novel-studio（或只拷贝 SKILL.md）
```

**Cursor**：把 `SKILL.md` 放入项目 `.cursor/rules/` 或 skills 目录。
**SkillHub**：直接提交本仓库（SKILL.md + README.md），按平台规范补充元信息。
**通用**：任何支持「技能文件作为系统提示词注入」的环境，把 SKILL.md 全文作为项目规则注入即可。

### DSH 版（DeepSeek Harness）

1. 安装插件 `dsh-novel-writer`（提供 novel_* 工具）；
2. 把 `DSH版/SKILL.md` 所在文件夹复制到技能目录：项目 `<工作区>/.dsh/skills/` 或用户技能目录；
3. 新会话自动加载；命中触发词（写小说/评分卡/世界观设定/章末钩子/网文章节等）即调用。

## 使用方式（两件套模式）

- 写某本书的章节：**书级 skill**（该书的必用词/世界观/人物/改稿规范）+ 本 skill（工艺层）；
- 新开一本书：先用 §2 一问一答法把世界观与词表建起来，再沉淀书级 skill；
- 只问工艺问题（评分卡/钩子/节奏）：直接用本 skill。

## 内容速览

1. 全局流程总览（建书 → 世界观 → 大纲 → 分章写 → 改稿 → 发布）
2. 世界观设定·一问一答法（问答清单 → 逐批提问附候选答案 → 答录跟踪 → 已确认结论 → 转正 → 读者友好层）
3. 章节写作工艺（文件结构三块 / 评分卡 11 字段与五维加权 / 章末钩子 8 条 / 节奏硬规则 / 评论诱导五选一 / 写前中后流程）
4. 番茄改稿对比学习（原稿 vs 改稿 → 可复现规律 → 沉淀书级改稿规范）
5. 平台适配（发布节奏 / 红线 / 追读）
6. 工具层（公开版=数据层文件约定；DSH 版=novel_* 工具映射表）
7. 批次与会话管理（4 章一批 / 单会话 12 章 / 规范永远最新）
